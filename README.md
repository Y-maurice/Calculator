# Calculator

A simple console-based calculator built using C# and .NET Framework.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling
- Repeated calculations without restarting

## Technologies

- C#
- .NET Framework
- Visual Studio

## How to Run

1. Clone the repository.
2. Open the `.sln` file in Visual Studio.
3. Build the project.
4. Run the application.

```text
Calculator

Enter first number: 10
Enter second number: 5
Operation: +
